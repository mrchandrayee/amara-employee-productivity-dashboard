A runnable responsive HTML/CSS/JavaScript reconstruction of the supplied 33-second screen recording.

## Run
Extract the ZIP and open `index.html` in a modern browser. No npm install or build tools are required.

Optional local server:
```bash
python3 -m http.server 8000
```
Open `http://localhost:8000`.

## Recreated modules and visible interactions
- Amara / Northstar Studio workspace layout with collapsible sidebar, workspace search and notifications.
- Dashboard greeting for Amara, team metrics, attendance ring, personal tasks, weekly activity chart, today's schedule and recent activity.
- People directory with department/status filters, search, employee detail drawer, edit status and add-person flow.
- Team schedule with weekly calendar view, upcoming time off and add-shift form.
- Time tracker with focus countdown, start/pause/reset, activity log and weekly summary.
- Time Off page with leave balances, pending requests, approve/decline interactions and request form.
- Onboarding cards, progress indicators, checklists and new onboarding form.
- Reports and insights cards, summary metrics and CSV export.
- Settings toggles and workspace preferences.

## Source extraction note
The recording shows the rendered Amara application and interactions, not a readable HTML/CSS/JS source editor. No original source code is visible to transcribe verbatim. The runnable app is reconstructed from the visible UI and screen states.

## Demo limitations
This is a frontend-only demo. Employee records, schedules, attendance, leave requests, tasks and analytics are local sample data. There is no backend, authentication, payroll, HRIS, real calendar integration or cloud persistence. Changes reset on refresh. The profile image loads from Unsplash and requires internet access.
